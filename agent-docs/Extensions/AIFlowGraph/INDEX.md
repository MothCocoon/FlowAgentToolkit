# AIFlowGraph Agent Knowledge Base - Index

$KB:flow:guide:aiflowgraph-index

## What this is

The AIFlowGraph section documents the **AIFlowGraph plugin** (`AIFlow.uplugin`), an official Flow
extension for AI and Behavior Tree blackboard support. Its articles cover the behavior and classes
provided by AIFlowGraph.

## Placement rule

Keep articles scoped to APIs and behavior owned by AIFlowGraph. Articles for other official plugins
live in their corresponding sections of this knowledge base.

## Concepts

- $KB:flow:concept:flow-blackboard-values - the Behavior Tree blackboard value system used by
  AIFlowGraph nodes.

## Nodes and AddOns

Query the catalog with `FindFlowNodeTypes` for the blackboard-setting node and the blackboard
comparison/configuration addons this plugin owns. Narrow the query with `AssetClassName`, `Kind`, and
`Query`, and select the needed `sections` value (`shape`, `brief`, or `full`).
